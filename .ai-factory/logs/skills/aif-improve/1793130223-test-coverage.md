# AC-18 v1.8 и AC-19 clear(): тесты, доказывающие требование

**Date:** 2026-10-27 19:43
**Plan:** .ai-factory/plans/feature-e1-core-client
**Severity:** medium

## Problem

Ни один тест не проверял фразу v1.8 «клиент Platform метрику token не пишет»; кейс AC-19 «токен после clear() не запрашивается» стоял на некэширующем TokenStub и ничего не доказывал; AC-11 runIf с абсолютным путём пользователя

## Root Cause

Требования обновлены во время планирования (r2), отрицательное условие новой фразы пропущено; подделка выбрана по удобству, а не по проверяемому свойству

## Solution

Task 28 — кейс без метрики token у клиента; Task 26 — проверка через clientCredentials и счётчик запросов к /oidc/token; Task 12 — путь к verdeect-platform от import.meta.url

## Prevention

Для каждого «не делает X» в AC планировать отрицательный кейс; подделку выбирать так, чтобы её поведение зависело от проверяемого свойства; в тестах не использовать абсолютные пути машины
