# Исключить test/consumer из корневого tsconfig

**Date:** 2026-10-27 20:56
**Plan:** .ai-factory/plans/feature-e2-nest-testing.md
**Severity:** low

## Problem

Корневой tsconfig включает test/, шаблоны потребителя импортируют архив пакета, который в корне не разрешается

## Root Cause

Новые каталоги с собственным package.json не сверены с include корня

## Solution

Task 2a добавляет test/consumer в exclude

## Prevention

При добавлении вложенных проектов проверять include/exclude корневых tsconfig и eslint
