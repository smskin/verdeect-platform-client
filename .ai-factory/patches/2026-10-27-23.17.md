# CHANGELOG при первых публичных экспортах и AC-7 «таймаут при живом снимке»

**Date:** 2026-10-27 23:17
**Files:** CHANGELOG.md, test/unit/client-freshness.spec.ts
**Severity:** low

## Problem

`/aif-verify --strict` после E1 упал на гейте «Library Package Gates»: в ядре появились публичные экспорты (`createPlatformAuthzClient`, `clientCredentials`, `PlatformUnavailableError`, `PlatformContractError`, 21 тип), а `CHANGELOG.md` не было. Кроме того, AC-7 перечисляет «503 / таймаут 2 с / обрыв» при снимке в пределах TTL, а таймаут был проверен только при пустом кэше.

## Root Cause

- План E1 следовал этапности `prd.md` §9 (README и CHANGELOG — E3). При этом правило проекта (`AGENTS.md`, skill-context `aif-verify`) требует запись в CHANGELOG на каждый новый публичный экспорт, а приоритет `prd.md` над этим правилом нигде не объявлен. Конфликт не был снят при планировании.
- Тесты AC-7 строились от плана, а не от дословного текста AC: таймаут посчитали эквивалентным 503, раз код ведёт их одной веткой `PlatformUnavailableError`. Доказательства для этой комбинации не было.

## Solution

- Добавлен `CHANGELOG.md` в формате Keep a Changelog, как у `verdeect-auth`: раздел `## [Unreleased]` → `### Added`, по строке на каждый экспорт `src/core/index.ts`. Версия не выпускается: `[Unreleased]` станет `1.0.0` в E3. README по-прежнему на E3.
- Добавлен тест `AC-7: снимок агента с epoch = 7 в пределах TTL, pep = 8, запрос к Platform не ответил за requestTimeoutMs (2000 мс) → …`: подделанные `setTimeout`/`clearTimeout` и ответ `'hang'`. Проверяет решение по снимку, `warn PLATFORM_UNAVAILABLE` с `reason: 'timeout'` и отсутствие запросов следующие 4 с. Код не менялся — тест сразу зелёный, поведение было верным.

## Prevention

- На этапе планирования библиотеки: если этап добавляет первый публичный экспорт, в план входит задача «CHANGELOG `[Unreleased]`», даже когда README и выпуск отложены PRD.
- Тесты AC писать по дословному тексту AC: каждое перечисление через «/» (503 / таймаут / обрыв) × каждое состояние (снимок есть / нет) — отдельный кейс или `it.each`, а не «эквивалентно по коду».
